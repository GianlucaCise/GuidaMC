Paper 1.21.11 · Solo systemd

Server Paper 1.21.11
solo systemd

// Plugin · Java 21 · No panel · Massima leggerezza

! Paper non supporta ancora 26.1. Usa 1.21.11 con Java 21.
⚙ Prerequisiti
  • Linux Mint 22.3
  • sudo
  • Java 21
  • wget
  • Porta 25565
01

Installa Java 21

bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y openjdk-21-jre-headless wget
02

Crea utente e cartella

bash
sudo useradd -r -m -d /opt/mcserver -s /bin/bash mcserver
sudo mkdir -p /opt/mcserver/paper
sudo chown -R mcserver:mcserver /opt/mcserver
03

Scarica Paper 1.21.11

bash
sudo -u mcserver wget \
  "https://api.papermc.io/v2/projects/paper/versions/1.21.11/builds/latest/downloads/paper-1.21.11-latest.jar" \
  -O /opt/mcserver/paper/paper.jar

# Prima avviata → genera i file
sudo -u mcserver bash
cd /opt/mcserver/paper
java -jar paper.jar nogui
sed -i 's/eula=false/eula=true/' eula.txt
exit
04

Service systemd

📄 /etc/systemd/system/mcserver.service
[Unit]
Description=Paper Minecraft 1.21.11
After=network.target

[Service]
User=mcserver
WorkingDirectory=/opt/mcserver/paper
ExecStart=/usr/bin/java \
  -Xms2G -Xmx4G \
  -XX:+UseG1GC \
  -XX:+ParallelRefProcEnabled \
  -XX:MaxGCPauseMillis=200 \
  -XX:+AlwaysPreTouch \
  -XX:+DisableExplicitGC \
  -jar paper.jar nogui
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
bash
sudo systemctl daemon-reload
sudo systemctl enable mcserver.service
sudo systemctl start mcserver.service
sudo journalctl -u mcserver.service -f
05

Plugin e port forwarding

bash — installa un plugin
sudo cp ~/Plugin.jar /opt/mcserver/paper/plugins/
sudo chown mcserver:mcserver /opt/mcserver/paper/plugins/Plugin.jar
sudo systemctl restart mcserver.service
