Vanilla 26.1 · Crafty Controller

Server Vanilla 26.1
+ Crafty

// Java 25 · Pannello web · No plugin

⚙ Prerequisiti
  • Linux Mint 22.3
  • sudo
  • Java 25
  • Python 3.10+
  • Git
  • Porta 25565
01

Installa Java 25 e dipendenze

Minecraft 26.1 richiede Java 25. Disponibile direttamente nei repo di Linux Mint 22 (base Ubuntu 24.04).

bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y openjdk-25-jre-headless git python3 python3-dev
java -version  # → openjdk 25.x.x
02

Installa Crafty Controller

!Linux Mint non è supportato ufficialmente. Se l'installer dà "distro not supported", sostituisci temporaneamente /etc/os-release fingendosi Ubuntu, esegui l'installer, poi ripristina.
bash
git clone https://gitlab.com/crafty-controller/crafty-installer-4.0.git
cd crafty-installer-4.0 && chmod +x install_crafty.sh
sudo ./install_crafty.sh  # scegli branch: master
✓Quando chiede di creare il service systemd, rispondi sì.
bash — avvia
sudo systemctl enable crafty.service
sudo systemctl start crafty.service

Pannello su https://localhost:8443. Credenziali in console al primo avvio.

iAvviso SSL self-signed = normale. Clicca "Avanzate" e prosegui.
03

Crea il server Vanilla in Crafty

Create a Server → Minecraft Java → Vanilla → 26.1 → Build Server!

!Prima avviata: apri eula.txt dall'editor di Crafty → eula=false → eula=true → riavvia.
04

JVM flags — ZGC per 26.1

In Crafty: Server Settings → JVM Arguments:

JVM flags
-Xms1G -Xmx4G
-XX:+UseZGC
-XX:+ZGenerational
-XX:+AlwaysPreTouch
-XX:+DisableExplicitGC
-Dfile.encoding=UTF-8
iMinecraft 26.1 usa ZGC al posto del vecchio G1GC — le Aikar's Flags classiche non si applicano qui.
