Paper 1.21.11 · Crafty Controller

Server Paper 1.21.11
+ Crafty

// Plugin Bukkit/Spigot · Java 21 · Pannello web

! Paper non supporta ancora Minecraft 26.1. Questa guida usa la versione stabile 1.21.11 con Java 21. Aggiorna appena Paper rilascia il supporto.
⚙ Prerequisiti
  • Linux Mint 22.3
  • sudo
  • Java 21
  • Python 3.10+
  • Git
  • Porta 25565
01

Installa Java 21 e dipendenze

bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y openjdk-21-jre-headless git python3 python3-dev
02

Installa Crafty Controller

!Linux Mint non è supportato ufficialmente. Se l'installer dà errore, usa il workaround con /etc/os-release.
bash
git clone https://gitlab.com/crafty-controller/crafty-installer-4.0.git
cd crafty-installer-4.0 && chmod +x install_crafty.sh
sudo ./install_crafty.sh  # branch: master
sudo systemctl enable crafty.service
sudo systemctl start crafty.service

Pannello su https://localhost:8443

03

Crea il server Paper in Crafty

Create a Server → Minecraft Java → Paper → 1.21.11 → Build Server!

!Prima avviata: eula.txt in Crafty → false→true → riavvia.
04

JVM flags — Aikar's Flags (G1GC)

In Crafty: Server Settings → JVM Arguments:

Aikar's Flags — Paper 1.21.11
-Xms2G -Xmx4G
-XX:+UseG1GC
-XX:+ParallelRefProcEnabled
-XX:MaxGCPauseMillis=200
-XX:+UnlockExperimentalVMOptions
-XX:+DisableExplicitGC
-XX:+AlwaysPreTouch
-XX:G1NewSizePercent=30
-XX:G1MaxNewSizePercent=40
-XX:G1HeapRegionSize=8M
-XX:G1ReservePercent=20
-XX:G1HeapWastePercent=5
-XX:G1MixedGCCountTarget=4
-XX:InitiatingHeapOccupancyPercent=15
-XX:G1MixedGCLiveThresholdPercent=90
-XX:SurvivorRatio=32
-XX:+PerfDisableSharedMem
-XX:MaxTenuringThreshold=1

06

Plugin — installazione

Scarica da hangar.papermc.io, modrinth.com o spigotmc.org. Copia il .jar in plugins/ tramite il File Manager di Crafty e riavvia. I client degli amici non devono installare nulla.
