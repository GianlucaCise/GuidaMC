Fabric 26.1 · Solo systemd

Server Fabric 26.1
solo systemd

// Mod loader · Java 25 · No panel · Massima leggerezza

⚙ Prerequisiti
  • Linux Mint 22.3
  • sudo
  • Java 25
  • wget
  • Porta 25565
01

Installa Java 25

bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y openjdk-25-jre-headless wget
02

Crea utente e cartella

bash
sudo useradd -r -m -d /opt/mcserver -s /bin/bash mcserver
sudo mkdir -p /opt/mcserver/fabric
sudo chown -R mcserver:mcserver /opt/mcserver
03

Scarica e avvia il Fabric Launcher

bash
sudo -u mcserver wget \
  "https://meta.fabricmc.net/v2/versions/loader/26.1/latest/stable/server/jar" \
  -O /opt/mcserver/fabric/fabric-server-launch.jar

# Prima avviata — Fabric scarica le librerie, poi va in crash per EULA
sudo -u mcserver bash
cd /opt/mcserver/fabric
java -jar fabric-server-launch.jar nogui
sed -i 's/eula=false/eula=true/' eula.txt
exit
✓Il primo avvio scarica automaticamente Minecraft e le librerie Fabric. Ci vorrà qualche minuto — normale.
04

Service systemd

📄 /etc/systemd/system/mcserver.service
[Unit]
Description=Fabric Minecraft 26.1
After=network.target

[Service]
User=mcserver
WorkingDirectory=/opt/mcserver/fabric
ExecStart=/usr/bin/java \
  -Xms2G -Xmx4G \
  -XX:+UseZGC \
  -XX:+ZGenerational \
  -XX:+AlwaysPreTouch \
  -XX:+DisableExplicitGC \
  -jar fabric-server-launch.jar nogui
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
bash
sudo systemctl daemon-reload
sudo systemctl enable mcserver.service
sudo systemctl start mcserver.service
sudo journalctl -u mcserver.service -f
05

Installare mod

bash
sudo -u mcserver mkdir -p /opt/mcserver/fabric/mods
sudo cp ~/fabric-api-x.x.x.jar /opt/mcserver/fabric/mods/
sudo chown mcserver:mcserver /opt/mcserver/fabric/mods/*.jar
sudo systemctl restart mcserver.service
!Mod gameplay devono stare anche su ogni client. Mod server-side (Lithium, Starlight) vanno solo sul server — client Vanilla OK.
