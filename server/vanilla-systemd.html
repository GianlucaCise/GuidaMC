Vanilla 26.1 · Solo systemd

Server Vanilla 26.1
solo systemd

// Massima leggerezza · Java 25 · No panel

i Cartella server: /opt/mcserver/vanilla — non /opt/minecraft, per non collidere con l'utente di Crafty se installato.
⚙ Prerequisiti
  • Linux Mint 22.3
  • sudo
  • Java 25
  • wget
  • Porta 25565
01

Installa Java 25

bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y openjdk-25-jre-headless wget
java -version  # → openjdk 25.x.x
02

Crea utente e cartella

bash
sudo useradd -r -m -d /opt/mcserver -s /bin/bash mcserver
sudo mkdir -p /opt/mcserver/vanilla
sudo chown -R mcserver:mcserver /opt/mcserver
03

Scarica il JAR ufficiale 26.1

iVai su minecraft.net/en-us/download/server, copia il link del bottone e usalo nel comando sotto.
bash
sudo -u mcserver wget "<URL_JAR_DA_MINECRAFT.NET>" \
  -O /opt/mcserver/vanilla/server.jar
04

Prima avviata + EULA

bash
# Entra come utente mcserver
sudo -u mcserver bash
cd /opt/mcserver/vanilla
java -jar server.jar nogui
# Si ferma → accetta EULA
sed -i 's/eula=false/eula=true/' eula.txt
exit
📄 /opt/mcserver/vanilla/server.properties
max-players=10
view-distance=8
white-list=true
difficulty=normal
online-mode=true
motd=Il nostro server 🎮
05

Service systemd

📄 /etc/systemd/system/mcserver.service
[Unit]
Description=Minecraft Vanilla 26.1
After=network.target

[Service]
User=mcserver
WorkingDirectory=/opt/mcserver/vanilla
ExecStart=/usr/bin/java \
  -Xms1G -Xmx4G \
  -XX:+UseZGC \
  -XX:+ZGenerational \
  -XX:+AlwaysPreTouch \
  -XX:+DisableExplicitGC \
  -jar server.jar nogui
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
bash
sudo systemctl daemon-reload
sudo systemctl enable mcserver.service
sudo systemctl start mcserver.service
sudo journalctl -u mcserver.service -f
