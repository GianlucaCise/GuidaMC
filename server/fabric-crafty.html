Fabric 26.1 · Crafty Controller

Server Fabric 26.1
+ Crafty

// Mod loader · Java 25 · Pannello web

i Fabric è ideale per mod di ottimizzazione (Lithium, Starlight) e QoL. Non supporta plugin Bukkit/Spigot — per quello usa Paper. Fabric Loader 0.18.4 supporta già 26.1.
⚙ Prerequisiti
  • Linux Mint 22.3
  • sudo
  • Java 25
  • Python 3.10+
  • Git
  • wget
  • Porta 25565
01

Installa Java 25 e dipendenze

bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y openjdk-25-jre-headless git python3 python3-dev wget
02

Installa Crafty Controller

bash
git clone https://gitlab.com/crafty-controller/crafty-installer-4.0.git
cd crafty-installer-4.0 && chmod +x install_crafty.sh
sudo ./install_crafty.sh  # branch: master
sudo systemctl enable crafty.service
sudo systemctl start crafty.service

Pannello su https://localhost:8443

03

Scarica il Fabric Server Launcher

bash
wget "https://meta.fabricmc.net/v2/versions/loader/26.1/latest/stable/server/jar" \
  -O ~/fabric-server-launch.jar
✓Scarica sempre l'ultima versione stabile del Fabric Loader (attualmente 0.18.4) per Minecraft 26.1.
04

Crea il server Fabric in Crafty

Create a Server → Minecraft Java → Custom JAR → carica fabric-server-launch.jar → Build Server!

!Prima avviata: Fabric scarica i file necessari, poi si ferma per la EULA. Apri eula.txt da Crafty → false→true → riavvia.
05

JVM flags — ZGC per 26.1

JVM flags — Fabric 26.1
-Xms2G -Xmx4G
-XX:+UseZGC
-XX:+ZGenerational
-XX:+AlwaysPreTouch
-XX:+DisableExplicitGC
-Dfile.encoding=UTF-8
06

Mod vs Plugin — differenza client

Mod server-side only

Lithium, Starlight, Carpet — il client non le vede. Un Vanilla si connette senza problemi.

Mod gameplay / contenuto

Devono stare sia sul server che su ogni client. Un Vanilla viene rifiutato.

Scarica mod da modrinth.com (versione 26.1 Fabric). Metti i .jar in mods/ via Crafty File Manager. Installa sempre Fabric API per prima.
