00

Come funziona il sistema

Simple Voice Chat

Mod/plugin che aggiunge la chat vocale di prossimità a Minecraft: i giocatori si sentono solo se sono abbastanza vicini in-game. Richiede installazione sia sul server che sul client di ogni giocatore che vuole usare la voce.

Simple Voice Chat Discord Bridge

Addon che collega Simple Voice Chat a un canale vocale Discord. Permette a chi non ha il client Minecraft (o usa Bedrock via Geyser) di sentire e parlare con i giocatori in-game tramite Discord. Funziona tramite bot Discord che entrano nel canale vocale.

Limitazione importante

Ogni bot Discord gestisce un solo utente alla volta nel canale vocale. Se vuoi che 3 persone Discord si colleghino contemporaneamente, devi creare e configurare 3 bot separati. Per un piccolo gruppo, 1-2 bot sono generalmente sufficienti.

Versioni supportate

Supporta Paper, Fabric e Purpur fino a Minecraft 1.21.x. Non ancora aggiornato a 26.1 — tieni d'occhio la pagina Modrinth per aggiornamenti.

i Porta UDP extra: Simple Voice Chat usa una porta UDP separata per l'audio (default 24454). Se vuoi usarlo fuori dalla LAN, dovrai aprirla sul router oltre alla 25565. Per ora in LAN non serve nulla di extra.

Prerequisiti — installa Simple Voice Chat

Il bridge richiede che Simple Voice Chat sia già installato e funzionante sul server. Installalo prima di procedere.

Paper (plugin)

Scarica da modrinth.com/mod/simple-voice-chat la versione Bukkit/Paper. Mettila in plugins/.

Fabric (mod)

Scarica da modrinth.com/mod/simple-voice-chat la versione Fabric. Mettila in mods/. Richiede Fabric API.

! Simple Voice Chat deve essere installato anche sul client di ogni giocatore che vuole usare la voce in-game. Chi non lo installa può comunque giocare normalmente, ma non sentirà né parlerà via voice chat in-game (potrà però usare il bridge Discord).

Avvia il server una volta con Simple Voice Chat per generare il suo config, poi fermalo. Verifica che nella console compaia qualcosa tipo [VoiceChat] Voice chat server started.

01

Crea i bot Discord

Serve un bot per ogni persona Discord che vuole connettersi contemporaneamente. Per iniziare, crea almeno un bot.

1. Vai al Developer Portal

URL
https://discord.com/developers/applications

2. Crea una nuova applicazione
Clicca New Application → dagli un nome (es. MC Voice 1) → Create.

3. Configura il bot

Copia il token

Menu a sinistra → Bot → Reset Token → copia il token. Salvalo — ti servirà nel config.

Disabilita Public Bot

Sempre nella tab Bot, scorri in basso e disabilita "Public Bot" — così nessun altro potrà invitare il tuo bot in altri server.

4. Prendi l'Application ID e genera il link di invito
Menu a sinistra → General Information → copia l'Application ID.
Poi apri questo URL nel browser, sostituendo l'ID:

URL invito bot — sostituisci YOUR_APP_ID
https://discord.com/api/oauth2/authorize?client_id=YOUR_APP_ID&permissions=36700160&scope=bot

Seleziona il tuo server Discord → Autorizza. Non disabilitare nessun permesso.

5. Copia l'ID del canale vocale Discord
In Discord: Impostazioni → App → Modalità sviluppatore → attiva. Poi tasto destro sul canale vocale che vuoi usare come bridge → Copia ID canale.

! Nel canale vocale Discord non possono esserci due persone che parlano contemporaneamente o ci saranno glitch audio. Imposta il limite utenti del canale a 2 (1 bot + 1 persona Discord) per evitare problemi.
i Se vuoi più di una persona Discord connessa contemporaneamente, ripeti questi step per ogni bot aggiuntivo — crea un'app separata e un canale vocale separato per ognuno.
02

Installazione — Paper (plugin)

Scarica da modrinth.com/plugin/simple-voice-chat-discord-bridge la versione Paper/Bukkit.

bash
sudo cp ~/voicechat-discord.jar /opt/mcserver/paper/plugins/
sudo chown mcserver:mcserver /opt/mcserver/paper/plugins/voicechat-discord.jar
# Avvia per generare il config
sudo systemctl restart mcserver.service
sudo systemctl stop mcserver.service

Apri plugins/voicechat-discord/config.yml:

📄 plugins/voicechat-discord/config.yml
bots:
    # Bot 1 — un bot per ogni persona Discord simultanea
    - token: IL_TUO_TOKEN_BOT_1
      vc_id: ID_CANALE_VOCALE_1

    # Bot 2 (opzionale — aggiungi altri se vuoi più utenti simultanei)
    # - token: IL_TUO_TOKEN_BOT_2
    #   vc_id: ID_CANALE_VOCALE_2
✓Riavvia il server. I bot appariranno online nel tuo server Discord.
03

Installazione — Fabric (mod)

Scarica da modrinth.com/plugin/simple-voice-chat-discord-bridge la versione Fabric. Richiede Fabric API e ovviamente Simple Voice Chat Fabric.

bash
sudo cp ~/voicechat-discord-fabric.jar /opt/mcserver/fabric/mods/
sudo chown mcserver:mcserver /opt/mcserver/fabric/mods/voicechat-discord-fabric.jar
sudo systemctl restart mcserver.service
sudo systemctl stop mcserver.service

Il config per Fabric è in config/voicechat-discord.yml — identico al Paper:

📄 config/voicechat-discord.yml
bots:
    - token: IL_TUO_TOKEN_BOT_1
      vc_id: ID_CANALE_VOCALE_1
04

Uso in-game

Una volta configurato, i giocatori in-game usano questi comandi per avviare/fermare una sessione vocale con Discord:

Console / in-game
# Avvia una sessione vocale — il bot entra nel canale Discord
/dvc start

# Ferma la sessione — il bot esce dal canale Discord
/dvc stop

# Lista dei gruppi vocali disponibili
/dvc group list

# Crea un gruppo vocale privato
/dvc group create NomeGruppo

Procedura per l'utente Discord:

Step 1 — giocatore in-game

Il giocatore in-game digita /dvc start. Il bot del server entra automaticamente nel canale vocale Discord configurato.

Step 2 — utente Discord

L'utente Discord entra nello stesso canale vocale dove è entrato il bot. Ora può sentire e parlare con il giocatore in-game in tempo reale.

i Il bot resta nel canale vocale finché il giocatore non usa /dvc stop o non esce dal server. Se il server si riavvia, il bot esce automaticamente.
