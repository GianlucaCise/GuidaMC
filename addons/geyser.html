GeyserMC · Floodgate · Crossplay Java ↔ Bedrock

Crossplay con
GeyserMC + Floodgate

// Paper 1.21.11 o Fabric 1.21.11 · Porta UDP 19132

00

Cosa sono e come funzionano

GeyserMC

Traduttore di protocollo Java ↔ Bedrock. I client Bedrock (mobile, console, Windows Edition) si connettono su una porta UDP separata, Geyser traduce tutto e li fa apparire come normali giocatori Java. I giocatori Java non notano nulla.

Floodgate

Companion di Geyser. Senza Floodgate i giocatori Bedrock avrebbero bisogno di un account Java a pagamento. Con Floodgate basta il loro account Microsoft/Xbox. Va installato sempre insieme a Geyser.

! Geyser supporta solo Minecraft Java 1.21.11 — non ancora 26.1. Usa Paper 1.21.11 o Fabric 1.21.11 per il crossplay. Tieni d'occhio geysermc.org per aggiornamenti.
i Geyser non funziona su Vanilla — serve obbligatoriamente Paper o Fabric.
01

Installazione su Paper (plugin)

Scarica entrambi i JAR da geysermc.org/download (versione Spigot/Paper):

bash — senza Crafty
sudo cp ~/Geyser-Spigot.jar /opt/mcserver/paper/plugins/
sudo cp ~/floodgate-spigot.jar /opt/mcserver/paper/plugins/
sudo chown mcserver:mcserver /opt/mcserver/paper/plugins/*.jar
✓Avvia il server una volta — Geyser e Floodgate generano i config. Poi fermalo per configurarli.
02

Installazione su Fabric (mod)

Scarica da geysermc.org/download le versioni Fabric. Richiede anche Fabric API.

bash
sudo cp ~/Geyser-Fabric.jar /opt/mcserver/fabric/mods/
sudo cp ~/floodgate-fabric.jar /opt/mcserver/fabric/mods/
sudo chown mcserver:mcserver /opt/mcserver/fabric/mods/*.jar
03

Configurazione Geyser (config.yml)

Paper

plugins/Geyser-Spigot/config.yml

Fabric

config/Geyser-Fabric/config.yml

📄 config.yml — sezioni chiave
bedrock:
  address: 0.0.0.0
  port: 19132        # porta UDP da aprire sul router
  clone-remote-port: false

remote:
  address: 127.0.0.1  # stessa macchina
  port: 25565
  auth-type: floodgate  # ← FONDAMENTALE: cambia da "online"

passthrough-motd: true
show-coordinates: true
!auth-type: floodgate è la riga più importante — senza questa i Bedrock avrebbero bisogno di un account Java.
04

Configurazione Floodgate

Path: plugins/floodgate/config.yml (Paper) · config/floodgate/config.yml (Fabric)

📄 floodgate/config.yml
# Prefisso nel nome giocatori Bedrock — li distingue nella whitelist
username-prefix: "."

# Permette di linkare account Bedrock a account Java
player-link:
  enabled: true
  enable-global-linking: true
iIl prefisso . davanti al nome è normale — lo vedrai nella whitelist come .NomeGiocatore.

Floodgate genera un key.pem — copialo nella cartella Geyser:

bash — Paper
sudo cp plugins/floodgate/key.pem plugins/Geyser-Spigot/
bash — Fabric
sudo cp config/floodgate/key.pem config/Geyser-Fabric/
!Non distribuire mai il key.pem. Chi lo ottiene può impersonare giocatori Bedrock sul tuo server.
05

Whitelist per giocatori Bedrock

Console Minecraft
whitelist add .NomeGiocatoreBedrock
whitelist list
✓Il punto davanti è obbligatorio. Es: .GigiGamer99 (gamertag Xbox esatto).

Verifica e comandi utili

Server di test GeyserMC
# Java Edition  IP: test.geysermc.org  Porta: 25565
# Bedrock Edition IP: test.geysermc.org  Porta: 19132
Console Minecraft
geyser list      # giocatori Bedrock connessi
geyser version   # versione Geyser attiva
geyser reload   # ricarica config senza riavviare
