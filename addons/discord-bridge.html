Chat Bridge · DiscordSRV · AMCDB

Chat Bridge
Minecraft ↔ Discord

// DiscordSRV per Paper · AMCDB per Fabric · server-side only

00

Panoramica

Cosa fa

Collega la chat in-game a un canale Discord. I messaggi scritti in-game appaiono su Discord e viceversa. Include notifiche morte, avanzamenti e console opzionale su un canale dedicato.

Cosa ti serve

Un server Discord. Un bot Discord creato dal Developer Portal — è l'app che si connette e manda i messaggi. Il token del bot va nel config del plugin/mod.

00

Crea il bot Discord — uguale per Paper e Fabric

1. Vai al Discord Developer Portal

URL
https://discord.com/developers/applications

2. Crea una nuova applicazione
Clicca New Application → dagli un nome (es. MC Bridge) → Create.

3. Configura il bot
Menu a sinistra → Bot. Poi:

Copia il token

Clicca Reset Token → conferma → copia il token. Salvalo — ti servirà nel config. Non condividerlo mai.

Abilita gli intents

Scorri in basso → Privileged Gateway Intents → abilita SERVER MEMBERS INTENT e MESSAGE CONTENT INTENT. Senza questi il bot non legge i messaggi.

4. Invita il bot nel tuo server Discord
Menu a sinistra → OAuth2 → URL Generator → Scopes: seleziona bot → Bot Permissions:

Permessi minimi
Read Messages / View Channels
Send Messages
Read Message History
Embed Links

Copia l'URL generato in fondo, aprilo nel browser, seleziona il tuo server → Autorizza.

! Il token è come una password. Non condividerlo e non metterlo in file pubblici. Se viene compromesso, fai Reset Token nel Developer Portal.

5. Copia l'ID del canale chat
In Discord: Impostazioni → App → Modalità sviluppatore → attiva. Poi tasto destro sul canale → Copia ID canale. Salvalo — serve nel config.

01

Paper — DiscordSRV (plugin)

Scarica il JAR da modrinth.com/plugin/discordsrv o da hangar.papermc.io.

bash — installa il plugin
# Con Crafty: usa il File Manager
# Senza Crafty:
sudo cp ~/DiscordSRV.jar /opt/mcserver/paper/plugins/
sudo chown mcserver:mcserver /opt/mcserver/paper/plugins/DiscordSRV.jar
# Avvia il server una volta per generare il config, poi fermalo
sudo systemctl restart mcserver.service
sudo systemctl stop mcserver.service

Apri plugins/DiscordSRV/config.yml:

📄 plugins/DiscordSRV/config.yml — righe chiave
# Token del bot Discord
BotToken: "IL_TUO_TOKEN_QUI"

# ID del canale chat
Channels: {"global": "ID_CANALE_QUI"}

# (Opzionale) Canale console — solo tu devi poter scrivere lì!
DiscordConsoleChannelId: "ID_CANALE_CONSOLE"

# Notifiche morte e avanzamenti su Discord
DiscordChatChannelGameDeathEventsEnabled: true
✓Riavvia il server. Usa /discordsrv reload in-game per ricaricare il config senza riavviare.
02

Fabric — AMCDB (mod)

AMCDB è leggero, server-side only e stabile. Scarica da modrinth.com/mod/amcdb. Richiede Fabric API.

bash
sudo cp ~/amcdb-x.x.x.jar /opt/mcserver/fabric/mods/
sudo chown mcserver:mcserver /opt/mcserver/fabric/mods/amcdb-x.x.x.jar
# Prima avviata — genera il config (va in crash, è normale)
sudo systemctl start mcserver.service
sudo systemctl stop mcserver.service
iIl primo avvio con AMCDB va in crash perché manca il config — è atteso. Il file viene creato, poi lo compili e riavvii.

Apri config/amcdb.properties:

📄 config/amcdb.properties — righe chiave
# Token del bot Discord
amcdb.discord.token=IL_TUO_TOKEN_QUI

# ID del canale chat
amcdb.discord.chat.channel=ID_CANALE_QUI

# (Opzionale) Canale console
amcdb.discord.console.channel=ID_CANALE_CONSOLE

# Abilita esecuzione comandi dal canale console (default: false)
amcdb.discord.channels.console.enableExecution=false
✓Riavvia il server. AMCDB lavora off-thread — impatto sulle performance praticamente zero.
!Se abiliti enableExecution=true, assicurati che solo tu possa scrivere nel canale console Discord.
03

Differenze tra DiscordSRV e AMCDB

La distinzione principale non è solo la lista di feature — è il pubblico a cui si rivolgono.

DiscordSRV — potente e configurabile

È il bridge più completo per Paper. Pensato per server con una community: supporta il link account (ogni giocatore può collegare il proprio account Discord al proprio account MC), la sincronizzazione dei ruoli Discord con i gruppi in-game, webhook personalizzati per ogni canale, e un sistema di alert configurabile per quasi ogni evento del server. La configurazione è più articolata ma ha una documentazione ottima. Per un piccolo server tra amici è un po' "overkill", ma funziona benissimo anche in quel contesto.

AMCDB — leggero e diretto

Pensato per chi vuole il bridge funzionante in 5 minuti senza toccare decine di opzioni. Non usa mixins (non modifica il codice di Minecraft direttamente), quindi è molto stabile tra una versione MC e l'altra. Tutto il lavoro viene fatto off-thread — zero impatto sulle performance del server. Manca il link account e la sincronizzazione ruoli, ma per un gruppo di amici non servono.

04

Alternative che esistono

Esistono altri bridge, ma non li consiglio come prima scelta per questo setup:

Discord Integration (DCIntegration)

Interessante perché supporta Fabric, Forge, NeoForge, Paper e Spigot tutto con un unico progetto. Però è in "life support" — il maintainer ha dichiarato che gli aggiornamenti arrivano quasi solo da PR della community. Non ancora aggiornato a 26.1.

Discord-MC-Chat (DMCC)

Alternativa Fabric con feature simili ad AMCDB. Ben mantenuto ma con meno download e community più piccola. Non ancora aggiornato a Minecraft 26.1 al momento.
