Mappa web 2D
Dynmap

// Mappa stile Google Maps · Web server integrato · Paper + Fabric

00

Cos'è Dynmap e quando usarlo

Cosa fa

Dynmap genera una mappa 2D del mondo Minecraft in stile Google Maps, accessibile da qualsiasi browser. Mostra la mappa dall'alto con aggiornamenti in tempo reale, posizione dei giocatori, e permette di zoomare e spostarsi. Include web server integrato sulla porta 8123.

Dynmap vs BlueMap

Dynmap: mappa 2D (top-down), più leggero sul render, stile classico, ottimo per server con CPU limitata. Supporta marker, chat web-to-game e aree configurabili.
BlueMap: mappa 3D con edifici veri, più bella visivamente ma usa più CPU e disco per il render. Scegli Dynmap se le risorse sono un fattore.

Versioni supportate

Dynmap per Paper supporta 1.21.11. La versione Fabric (Dynmap-Forge/Fabric) è all'ultima release 3.8 su 1.21.11 — non ancora 26.1. Controlla CurseForge per aggiornamenti.

Server-side only

I client degli amici non devono installare nulla. Dynmap gira interamente lato server. Aprono il browser e navigano all'URL della mappa.

01

Installazione su Paper (plugin)

Scarica il JAR da spigotmc.org/resources/dynmap.274 o modrinth.com/plugin/dynmap. Scegli la versione per Paper/Spigot (non Forge/Fabric).

bash — senza Crafty
sudo cp ~/Dynmap.jar /opt/mcserver/paper/plugins/
sudo chown mcserver:mcserver /opt/mcserver/paper/plugins/Dynmap.jar
✓Con Crafty: usa il File Manager per caricare il JAR nella cartella plugins/.

Avvia il server una volta per generare i file di configurazione, poi fermalo.

Configura il web server — apri plugins/dynmap/configuration.txt:

📄 plugins/dynmap/configuration.txt — righe chiave
# Indirizzo su cui ascolta (0.0.0.0 = tutte le interfacce)
webserver-bindaddress: 0.0.0.0

# Porta del web server (default 8123)
webserver-port: 8123

# Qualità del render — "lowres" è più leggero, "hires" più bello
# Per un server tra amici con poca CPU, usa lowres
deftemplatesuffix: lowres

# Aggiornamento mappa in secondi (default 0 = real-time)
update-rate: 1

# Mostra i giocatori sulla mappa
player-tracking: true
✓Riavvia il server. Dynmap avvierà automaticamente il web server. Poi fai il primo render dalla console.
02

Installazione su Fabric (mod)

Scarica il JAR Fabric-specifico da CurseForge (cerca "Dynmap-Forge/Fabric") o modrinth.com/mod/dynmap. Assicurati di scegliere la versione Fabric per la tua versione MC — non Forge.

!A differenza di BlueMap, Dynmap per Fabric richiede il JAR specifico per ogni versione di MC. Scarica Dynmap-x.x-fabric-1.21.11.jar per MC 1.21.11. Non usare il JAR Spigot/Paper su Fabric.
bash
sudo cp ~/Dynmap-fabric.jar /opt/mcserver/fabric/mods/
sudo chown mcserver:mcserver /opt/mcserver/fabric/mods/Dynmap-fabric.jar

# Avvia il server una volta per generare i config, poi fermalo
sudo systemctl restart mcserver.service
sudo systemctl stop mcserver.service

Il file di configurazione per Fabric è in config/dynmap/configuration.txt. Le opzioni sono identiche alla versione Paper:

📄 config/dynmap/configuration.txt — righe chiave
webserver-bindaddress: 0.0.0.0
webserver-port: 8123
deftemplatesuffix: lowres
update-rate: 1
player-tracking: true
03

Primo render e comandi

Al primo avvio la mappa apparirà nera — il mondo non è ancora stato renderizzato. Avvia il render manualmente dalla console Minecraft:

Console Minecraft
# Render completo del mondo (si aggiorna man mano nel browser)
/dynmap fullrender world

# Render solo di un'area intorno alla posizione attuale (più veloce per test)
/dynmap radiusrender 500

# Cancella e riavvia il render
/dynmap cancelrender world
/dynmap fullrender world

# Stato del render in corso
/dynmap stats

# Pausa / ripresa
/dynmap pause all
/dynmap pause none
iIl render avviene in background e non blocca il gioco. Puoi giocare normalmente mentre viene processato. La mappa si aggiorna progressivamente nel browser — ricarica la pagina se non vedi cambiamenti.
04

Come accedere alla mappa

URL — da questo PC
http://localhost:8123
URL — da altri PC nella LAN
http://<IP-locale-del-server>:8123
# Esempio: http://192.168.1.100:8123
iPer ora la mappa è accessibile solo in LAN. L'esposizione pubblica via port forwarding (porta 8123 TCP) la gestiamo separatamente.

Funzionalità della mappa nel browser:

Navigazione

Click + trascina per spostarsi. Scroll per zoom. I tasti freccia funzionano anche da tastiera.

Giocatori online

Le facce dei giocatori appaiono sulla mappa in tempo reale con il nome. Click per centrare la vista su di loro.

Dimensioni e layer

Nel menu a sinistra puoi switchare tra Overworld, Nether e End. Puoi anche scegliere tra vista surface, flat (solo biomi), e cave.

Chat web

Chi visualizza la mappa nel browser può chattare con i giocatori in-game tramite la chat box integrata (se abilitata nella config).

05

Marker personalizzati (opzionale)

Puoi aggiungere marker sulla mappa per segnare luoghi importanti (spawn, basi, negozi). Da console o in-game con i permessi:

Console / in-game
# Aggiungi un marker alla posizione X Y Z
/dmarker add label:"Spawn" icon:house x:0 y:64 z:0 world:world

# Lista di tutti i marker
/dmarker list

# Rimuovi un marker
/dmarker delete id:Spawn
06

Ottimizzazione per server con poca CPU

📄 configuration.txt — parametri performance
# Thread per il render (riduci se il server va lento)
render-thread-count: 1

# Usa lowres per render più veloci
deftemplatesuffix: lowres

# Aggiorna la mappa ogni N secondi invece di real-time
update-rate: 5

# Disabilita il render notturno (risparmia CPU)
fullrenderday-only: true
✓Con il tuo Ryzen 7 e solo 6 giocatori puoi usare tranquillamente le impostazioni di default. Riduci solo se noti cali di TPS durante il render completo.
