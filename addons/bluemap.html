BlueMap · Mappa 3D · Web Browser · Paper + Fabric

Mappa web 3D
BlueMap

// Mappa interattiva 3D · Web server integrato · Paper + Fabric

00

Cos'è BlueMap

Cosa fa

BlueMap genera una mappa 3D interattiva del mondo Minecraft, visualizzabile da qualsiasi browser. Mostra edifici in 3D con illuminazione realistica, posizione dei giocatori online in tempo reale, e permette di muoversi liberamente sulla mappa come su Google Maps. Include un web server integrato sulla porta 8100.

Compatibilità

Funziona sia come plugin Paper (Spigot/Paper) che come mod Fabric. Il rendering avviene in background su thread separati — non impatta il gameplay. Supporta Overworld, Nether e End separatamente.

Come accedervi

Una volta configurato, la mappa è accessibile da browser su http://<IP-del-server>:8100. Per ora la esponi solo in LAN — l'apertura pubblica via port forwarding o reverse proxy la gestiamo separatamente.

Server-side only

I client degli amici non devono installare nulla. BlueMap gira interamente lato server. È sufficiente aprire il browser e navigare all'URL della mappa.

i BlueMap vs Dynmap: Dynmap genera mappe 2D in stile Google Maps (più leggero). BlueMap genera mappe 3D con edifici veri (più bello ma usa più CPU/disco per il primo render). Per un server tra amici con una mappa non enorme, entrambi vanno bene — BlueMap è più moderno e visivamente superiore.
01

Installazione su Paper (plugin)

Scarica il JAR da hangar.papermc.io/Blue/BlueMap o modrinth.com/plugin/bluemap.

bash — senza Crafty
sudo cp ~/BlueMap.jar /opt/mcserver/paper/plugins/
sudo chown mcserver:mcserver /opt/mcserver/paper/plugins/BlueMap.jar
✓Con Crafty: usa il File Manager per caricare il JAR nella cartella plugins/.

Avvia il server una volta per generare i file di configurazione, poi fermalo:

bash
sudo systemctl restart mcserver.service
# Aspetta che il server sia partito completamente, poi fermalo
sudo systemctl stop mcserver.service

Accetta la EULA di BlueMap (richiesta per scaricare le texture di Minecraft):

📄 plugins/BlueMap/core.conf — riga da modificare
# Cambia da false a true per accettare la EULA di Mojang
accept-download: true

Configura il web server:

📄 plugins/BlueMap/webserver.conf
# Indirizzo su cui ascolta (0.0.0.0 = tutte le interfacce)
ip: "0.0.0.0"

# Porta del web server (default 8100)
port: 8100

# Se vuoi accessibile solo in LAN metti 127.0.0.1 invece di 0.0.0.0
✓Riavvia il server. BlueMap inizierà a scaricare le texture e a fare il primo render del mondo. Ci vorrà del tempo (dipende dalla dimensione della mappa).
02

Installazione su Fabric (mod)

Scarica da modrinth.com/mod/bluemap la versione Fabric. Non richiede Fabric API come dipendenza — è standalone.

bash
sudo cp ~/BlueMap-Fabric.jar /opt/mcserver/fabric/mods/
sudo chown mcserver:mcserver /opt/mcserver/fabric/mods/BlueMap-Fabric.jar

# Avvia per generare i config
sudo systemctl restart mcserver.service
sudo systemctl stop mcserver.service

I file di configurazione sono in config/bluemap/ invece che in plugins/BlueMap/:

📄 config/bluemap/core.conf
accept-download: true
📄 config/bluemap/webserver.conf
ip: "0.0.0.0"
port: 8100
03

Primo render e comandi

Dopo il riavvio BlueMap scarica le texture e inizia a renderizzare in background. Puoi accelerarlo o controllarlo con questi comandi dalla console Minecraft:

Console Minecraft
# Controlla lo stato del render
/bluemap

# Forza il render completo del mondo (lento ma completo)
/bluemap render world

# Ferma il render in corso
/bluemap stop

# Riprende il render
/bluemap start

# Aggiorna un'area specifica intorno alla posizione X Z
/bluemap render world 0 0 500
! Il primo render completo può richiedere da minuti a ore dipendendo dalla dimensione del mondo. BlueMap usa i thread in background e non impatta il gameplay, ma consuma CPU. Considera di avviarlo di notte o quando il server è poco usato.
04

Come accedere alla mappa

Una volta che BlueMap è avviato e ha fatto almeno un po' di render, apri nel browser:

URL — da questo PC
http://localhost:8100
URL — da altri PC nella LAN
http://<IP-locale-del-server>:8100
# Esempio: http://192.168.1.100:8100
i Per ora la mappa è accessibile solo in LAN. L'esposizione pubblica via port forwarding (porta 8100 TCP) o reverse proxy (nginx/caddy per servire su un URL con dominio) la gestiamo separatamente quando sei pronto.

Controlli nella mappa:

Navigazione

Click + trascina per spostare la visuale. Scroll per zoom. Click destro + trascina per ruotare e inclinare la vista 3D.

Giocatori online

I giocatori connessi appaiono sulla mappa in tempo reale con il loro nome. Puoi cliccarci sopra per vedere la posizione esatta.

Dimensioni

Nel menu laterale puoi switchare tra Overworld, Nether e End (se le hai esplorate e renderizzate).

Modalità mappa

Puoi passare da vista 3D a vista isometrica flat dal menu. La flat è più leggera per browser datati.

05

Ottimizzazione (server con poca RAM)

BlueMap di default può usare molte risorse durante il render. Con 8GB di RAM puoi stare tranquillo, ma se noti lag durante il primo render, modifica questi parametri:

📄 core.conf — parametri performance
# Thread dedicati al render (default: dipende dalla CPU)
# Riduci a 1-2 se il server va lento durante il render
render-thread-count: 2

# Quanti MB di RAM dedica al render (default: 100)
# Aumenta se hai spazio, riduci se sei a corto di RAM
scan-settings:
  max-tiles-per-cycle: 50
✓Per limitare l'area renderizzata e risparmiare spazio disco, imposta un world border in Minecraft prima di fare il render completo. BlueMap rispetta il bordo del mondo.
06

Port forwarding (quando vorrai renderla pubblica)
