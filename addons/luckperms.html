Gestione permessi
LuckPerms

// Gruppi · Permessi granulari · No OP ai giocatori

00

Il problema e la soluzione

Su Minecraft vanilla, per dare a un giocatore accesso a un comando (es. /time set day) devi renderlo OP — e un OP ha accesso a tutto, incluso cancellare il mondo o kickare chiunque. LuckPerms risolve questo creando gruppi con permessi specifici: puoi dare a un amico solo i comandi che vuoi, nessuno di più.

Come funziona

Crei dei gruppi (es. default, amico, admin), assegni permessi ai gruppi, e metti ogni giocatore nel gruppo corretto. Se un giocatore è in amico, eredita tutti i permessi di amico — e se amico eredita da default, anche quelli.

Paper vs Fabric

Su Paper i comandi vanilla hanno già i loro nodi permesso — LuckPerms da solo basta. Su Fabric i comandi vanilla non hanno nodi nativi: serve installare anche VanillaPermissions che li aggiunge.

Web editor

LuckPerms include un editor web a cui accedi con /lp editor — ti dà un link da aprire nel browser. Gestisci tutto da interfaccia grafica, poi premi Save e incolla il comando generato nella console. Zero comandi a memoria.

Supporto versioni

LuckPerms supporta Paper e Fabric su tutte le versioni recenti, inclusa 26.1 (aggiornato il 26 marzo 2026). Server-side only — i client non devono installare nulla.

01

Installazione — Paper

Scarica il JAR da modrinth.com/plugin/luckperms (versione Bukkit/Paper) o da luckperms.net.

bash
sudo cp ~/LuckPerms-Bukkit.jar /opt/mcserver/paper/plugins/
sudo chown mcserver:mcserver /opt/mcserver/paper/plugins/LuckPerms-Bukkit.jar
sudo systemctl restart mcserver.service
✓Su Paper i comandi vanilla hanno già i nodi permesso integrati — non serve nient'altro. LuckPerms da solo basta.
02

Installazione — Fabric

Su Fabric servono due mod: LuckPerms e VanillaPermissions. La prima gestisce i gruppi, la seconda espone i comandi vanilla come nodi permesso.

bash
# LuckPerms — da modrinth.com/plugin/luckperms (versione Fabric)
sudo cp ~/LuckPerms-Fabric.jar /opt/mcserver/fabric/mods/

# VanillaPermissions — da modrinth.com/mod/vanilla-permissions
sudo cp ~/VanillaPermissions.jar /opt/mcserver/fabric/mods/

sudo chown -R mcserver:mcserver /opt/mcserver/fabric/mods/
sudo systemctl restart mcserver.service
i VanillaPermissions espone ogni comando vanilla nel formato minecraft.command.<comando> — ad esempio minecraft.command.time per /time. Per dare accesso completo a un comando usa il wildcard minecraft.command.time.*.
03

Pianifica la struttura dei gruppi

Prima di creare i gruppi, pianifica chi fa cosa. Per un server tra amici una struttura semplice come questa è più che sufficiente:

default — tutti i giocatori, permessi base (chat, /spawn, /home)
↑ eredita
amico — amici fidati, comandi extra (/time, /weather, /tpa…)
↑ eredita
admin — tu, accesso completo (rimani OP + LuckPerms admin)
iL'ereditarietà funziona verso l'alto: amico ha tutti i permessi di default più i suoi. admin ha tutto di entrambi. Non devi duplicare i permessi.
04

Metodo A — Web editor (consigliato)

Il modo più semplice per gestire LuckPerms è il web editor. Apri la sessione dalla console del server o in-game da admin:

Console / in-game
/lp editor

LuckPerms stampa un link nella console (es. https://luckperms.net/editor/...). Aprilo nel browser — si apre l'editor grafico. Da qui puoi:

Creare gruppi

Clicca il + accanto a "Groups" nella barra sinistra. Dai un nome al gruppo (es. amico).

Aggiungere permessi

Seleziona un gruppo → tab "Permissions" → scrivi il nodo permesso → clicca il +. Puoi aggiungerne quanti vuoi prima di salvare.

Impostare ereditarietà

Seleziona un gruppo → tab "Parents" → aggiungi il gruppo da cui ereditare (es. amico eredita da default).

Salvare

Clicca Save in alto a destra → l'editor genera un comando. Copiaincollalo nella console del server. Le modifiche sono attive immediatamente.

✓Puoi fare tutte le modifiche che vuoi nell'editor e applicarle in un colpo solo con un singolo comando. Non devi salvare ad ogni modifica.
05

Metodo B — Comandi da console

Se preferisci usare la console direttamente, ecco i comandi per replicare la struttura default → amico → admin:

Console — crea i gruppi
# Crea i gruppi (default esiste già)
lp creategroup amico
lp creategroup admin

# Imposta il peso (priorità) — numero più alto = priorità maggiore
lp group default setweight 10
lp group amico   setweight 50
lp group admin   setweight 100

# Ereditarietà: amico eredita da default, admin da amico
lp group amico parent add default
lp group admin parent add amico
Console — aggiungi permessi ai gruppi
# Gruppo default — permessi base (esempi)
lp group default permission set minecraft.command.me true
lp group default permission set minecraft.command.msg true

# Gruppo amico — comandi extra
lp group amico permission set minecraft.command.time true
lp group amico permission set minecraft.command.weather true
lp group amico permission set minecraft.command.gamemode true
lp group amico permission set minecraft.command.gamemode.survival true
lp group amico permission set minecraft.command.gamemode.adventure true

# Per negare esplicitamente un permesso — usa false
lp group default permission set minecraft.command.op false
Console — assegna giocatori ai gruppi
# Metti un giocatore in un gruppo
lp user NomeGiocatore parent set amico

# Controlla in quale gruppo è un giocatore
lp user NomeGiocatore info

# Rimuovi un giocatore da un gruppo (torna a default)
lp user NomeGiocatore parent remove amico
iIn console ometti il / davanti ai comandi. In-game da admin metti /lp invece di lp.
06

Nodi permesso — riferimento rapido

I nodi seguono sempre il formato minecraft.command.<comando> su Fabric con VanillaPermissions, e lo stesso formato su Paper. Il wildcard .* alla fine dà accesso a tutti i sottocomandi.

ComandoNodo permessoNote
/time setminecraft.command.time.*giorno/notte/ora
/weatherminecraft.command.weather.*pioggia/sereno/tuono
/gamemode survivalminecraft.command.gamemode.survivalsolo survival, non creative
/gamemode (tutti)minecraft.command.gamemode.*tutti i modi incluso creative
/tpminecraft.command.teleport.*teleport a coordinate o giocatori
/giveminecraft.command.give.*⚠ darebbe poteri enormi, usa con cura
/killminecraft.command.kill.*⚠ può killare altri giocatori
/banminecraft.command.ban.*solo per admin fidati
/kickminecraft.command.kick.*solo per admin fidati
/gameruleminecraft.command.gamerule.*⚠ può disabilitare danni ecc.
/meminecraft.command.memessaggi narrativi in chat
/msgminecraft.command.msg.*messaggi privati
/seedminecraft.command.seedmostra il seed del mondo
! Su Paper il formato dei nodi è lo stesso (minecraft.command.time ecc.) ma dipende anche dai plugin installati — ogni plugin ha i propri nodi documentati nella sua pagina. Controlla sempre la documentazione del plugin specifico.
07

Comandi di controllo e debug

Console / in-game
# Apri il web editor (genera link)
lp editor

# Lista di tutti i gruppi esistenti
lp listgroups

# Info e permessi di un gruppo
lp group amico info
lp group amico permission info

# Controlla se un giocatore ha un permesso specifico
lp user NomeGiocatore permission check minecraft.command.time

# Tutti i permessi di un giocatore (compresi quelli ereditati)
lp user NomeGiocatore permission info

# Ricarica LuckPerms (dopo modifiche manuali ai file)
lp reload
08

Setup rapido — esempio completo per un server tra amici

Incolla questi comandi in sequenza nella console per avere una configurazione funzionante in un minuto:

Console — setup completo
# 1. Crea i gruppi e imposta l'ereditarietà
lp creategroup amico
lp creategroup admin
lp group amico parent add default
lp group admin parent add amico
lp group default setweight 10
lp group amico setweight 50
lp group admin setweight 100

# 2. Permessi gruppo amico
lp group amico permission set minecraft.command.time.* true
lp group amico permission set minecraft.command.weather.* true
lp group amico permission set minecraft.command.gamemode.survival true
lp group amico permission set minecraft.command.gamemode.adventure true
lp group amico permission set minecraft.command.msg.* true
lp group amico permission set minecraft.command.me true

# 3. Assegna i giocatori — sostituisci con i nomi reali
lp user Amico1 parent set amico
lp user Amico2 parent set amico
lp user TuoNome parent set admin
✓Dopo aver assegnato i giocatori ai gruppi puoi togliere l'OP agli amici con deop NomeGiocatore dalla console. Mantieni l'OP solo per te.
