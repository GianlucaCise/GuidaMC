🖥 Software Server — girano su una macchina e ospitano il mondo
Vanillaserver

Il server ufficiale di Mojang. Nessun plugin, nessuna mod. È il punto di partenza da cui deriva tutto il resto. Supporta l'ultima versione MC non appena Mojang la rilascia.

ufficiale Mojangno plugin26.1 ✓
Bukkitserver

Il primo progetto a introdurre un'API per plugin nel 2011. Non più sviluppato attivamente ma ha definito lo standard dei plugin MC. Oggi non si usa direttamente — Spigot e Paper lo hanno sostituito mantenendo la compatibilità.

storicoAPI plugindeprecato
Spigotfork di Bukkit

Fork ottimizzato di Bukkit, ancora molto usato. Migliora le performance e supporta plugin Bukkit. Oggi Paper è generalmente preferito, ma Spigot rimane la base per moltissimi plugin esistenti.

plugin Bukkitottimizzatobase di Paper
Paperfork di Spigot

Fork di Spigot con ottimizzazioni aggressive, bug fix e API estese. Il server più usato al mondo per plugin. Compatibile con tutti i plugin Bukkit/Spigot. Ha anche una propria API aggiuntiva (Paper API).

plugin Bukkit/Spigot/Papermolto diffuso1.21.11
Purpurfork di Paper

Fork di Paper con ancora più opzioni di configurazione e feature extra (mob personalizzabili, gameplay tweaks). Compatibile con tutti i plugin Paper/Spigot/Bukkit. Ottima scelta se vuoi più controllo di Paper.

plugin Paper+altamente configurabilefork di Paper
Foliafork di Paper

Fork sperimentale di Paper con multithreading regionalizzato: divide la mappa in regioni indipendenti su thread separati. Ottimo per server enormi. Però rompe la compatibilità con molti plugin — non tutti i plugin Paper funzionano.

multithreadingserver grandiplugin limitati
Fabricmod loader

Mod loader leggero e modulare. Aggiorna velocemente alle nuove versioni MC. Ideale per mod di ottimizzazione, QoL e mod leggere. Non supporta plugin Bukkit/Spigot. Richiede che le mod gameplay siano installate anche sul client.

modleggero26.1 ✓no plugin Bukkit
Forgemod loader

Il mod loader storico dal 2011. Supporta migliaia di mod pesanti (tecnologia, magia, dimensioni) e i grandi modpack come FTB, ATM, Enigmatica. Più lento ad aggiornarsi rispetto a Fabric. Oggi coesiste con NeoForge.

mod pesantimodpack FTB/ATMstorico
NeoForgefork di Forge

Fork di Forge nato nel 2023 da una scissione del team originale. È diventato rapidamente il successore de facto di Forge per le versioni MC moderne. Compatibile con la maggior parte delle mod Forge. Preferito per le nuove versioni.

fork di Forgeversioni recentimodpack moderni
Quiltfork di Fabric

Fork di Fabric nato nel 2021 con API più ricca e governance più aperta. Compatibile con la maggior parte delle mod Fabric. Meno diffuso di Fabric ma con community attiva. In pratica un'alternativa con qualche feature in più.

fork di Fabriccompatibile Fabriccommunity-driven
Legacy Fabricmod loader

Port non ufficiale di Fabric per versioni vecchie di Minecraft (dalla 1.0 alla 1.12.2 circa). Utile solo se vuoi girare un server su versioni datate usando l'ecosistema Fabric. Non compatibile con le mod Fabric moderne — ogni versione MC ha le sue mod specifiche. Irrilevante per server su versioni recenti.

versioni vecchie1.0–1.12.2non ufficiale
LiteLoadermod loader

Mod loader storico per versioni 1.5–1.12, ora completamente abbandonato. Serviva principalmente per mod client-side leggere come minimap e tweaker di chat. Non compatibile con le mod Forge/Fabric. Superato e non aggiornato da anni — menzioniamolo solo perché potresti trovarlo citato in guide vecchie.

abbandonato1.5–1.12solo client-side
🔀 Proxy / Network — si mettono davanti a più server e gestiscono il routing
BungeeCordproxy

Il proxy storico per i network Minecraft. Permette di collegare più server (lobby, survival, minigame) in modo che i giocatori si spostino senza disconnettersi. Non più mantenuto attivamente — Velocity lo ha superato.

network multi-serverstoricosostituito da Velocity
Waterfallfork di BungeeCord

Fork di BungeeCord mantenuto dal team di Paper. Più stabile e performante dell'originale. Mantiene la compatibilità con i plugin BungeeCord. Anch'esso superato da Velocity per i setup moderni.

fork BungeeCordplugin BungeeCordteam Paper
Velocityproxy

Il proxy moderno e raccomandato. Scritto da zero per essere veloce e sicuro. Ha il proprio sistema di plugin (non compatibile con BungeeCord) ma è molto più performante. Supportato attivamente dal team di Paper. La scelta per nuovi network.

modernoperformanteconsigliatoproprio sistema plugin
GeyserMCbridge / plugin

Traduttore di protocollo Java ↔ Bedrock. Permette ai giocatori Bedrock di connettersi a server Java. Gira come plugin (Paper), mod (Fabric) o proxy standalone. Funziona con Floodgate per l'autenticazione Xbox.

crossplayJava↔Bedrockplugin/mod/proxy
